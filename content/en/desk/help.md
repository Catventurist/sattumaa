**New here?** This page covers the basics. Every app opens in a window on the desktop, and you can open as many as you like.

::callout{icon="i-lucide-search" color="info"}
Press :kbd{value="meta"} :kbd{value="o"} or use the search button in the tray to open **Run**. Type an app name to open it, or pick a language.
::

## Getting started

::steps{level="3"}
### Open an app

Pick an app from the [index page](/win), the Start menu, or Run.

### Move and resize your windows

Drag a window by its title bar. Use the minus button to minimize it to the taskbar, and the cross to close it. The window you click last stays on top.

### Come back later

Settings such as volume, picture order and open windows stay in your browser, so the desktop looks the same next time.
::

## Using the apps

::::accordion
:::accordion-item{label="Files in Explorer" icon="i-lucide-folder"}
Browse folders in the tree, follow the breadcrumb to go back, and use the context menu to work with files. Renaming happens inline. Deleted files go to the recycle bin first. A file opens in the app that matches its type.
:::

:::accordion-item{label="Music and video" icon="i-lucide-circle-play"}
Media player has a queue, a playlist and a speed menu. The Music popover in the tray plays from the same queue, with repeat and a volume that is remembered.
:::

:::accordion-item{label="Pictures and Paint" icon="i-lucide-image" }
Drag pictures in the grid to reorder them, and open one in the viewer. Paint saves your drawing as a WebP image into Pictures.
:::

:::accordion-item{label="Clock and alarms" icon="i-lucide-clock"}
Clock has world clocks, a calendar, a stopwatch, a timer and alarms. Alarms keep ringing even when the Clock window is closed, as long as the page is open.
:::

:::accordion-item{label="Notes, Messages and Board" icon="i-lucide-notebook-pen"}
Notes is a rich text editor. Messages is a simple chat. Board holds spreadsheets for lists and small tables.
:::

:::accordion-item{label="Browser" icon="i-lucide-globe"}
Open several tabs, go back through the history, and visit the retro GeoTowns sites with guestbooks and hit counters.
:::
::::

## Change the language

Open Run and choose a language under **Language**. Every app follows, including dates and component labels. English and Finnish are available.

## Troubleshooting

::::accordion
:::accordion-item{label="A window is missing" icon="i-lucide-app-window"}
Look for it in the taskbar. A minimized window stays there until you select it. If it is not there, open it again from Run.
:::

:::accordion-item{label="The camera or microphone does not work in a meeting" icon="i-lucide-video-off"}
Allow access when the browser asks, and check the browser's site settings for this page. Both start off by default.
:::

:::accordion-item{label="My settings are gone" icon="i-lucide-hard-drive"}
Settings are stored in your browser. Clearing site data or using a private window removes them.
:::
::::
